
# 猜数字小游戏

## 一、项目介绍

这是我使用 Python 编写的一个简单猜数字小游戏，也是计算机协会的入门练习项目。

## 二、游戏功能

- 电脑随机生成一个 1～100 的整数
- 玩家输入自己猜测的数字
- 猜大了会提示“大了”
- 猜小了会提示“小了”
- 猜中后显示猜测次数

## 三、运行方法

1. 电脑需要安装 Python
2. 打开 CMD 命令提示符
3. 进入项目文件夹：

```cmd
cd /d D:\play_do\first
```

4. 运行游戏：

```cmd
python game.py
```

## 四、使用技术

- Python
- random 随机数模块
- while 循环
- if / elif / else 条件判断

## 五、学习收获

通过这个项目，我学习了 Python 的变量、随机数、循环和条件判断，也掌握了使用 CMD 运行 Python 程序的基本方法。
